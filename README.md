# Frontend Mentor - QR Code Component

This is my solution to the [QR code component challenge](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) from Frontend Mentor.

The goal of this challenge was to build a responsive QR code component as closely as possible to the provided design while practicing fundamental HTML and CSS skills.

## Screenshot

![QR Code Component](./design/desktop-design.jpg)

## Built With

* HTML5
* CSS3
* Flexbox
* Responsive design
* Google Fonts - Outfit

## What I Learned

This project helped me practice and strengthen several fundamental frontend development concepts:

* Structuring a page with semantic HTML
* Using Flexbox to center content vertically and horizontally
* Creating responsive layouts with percentages and `max-width`
* Working with CSS spacing using `padding`, `margin`, and `gap`
* Using `box-sizing: border-box`
* Understanding viewport units such as `vh`
* Using CSS transitions and hover effects
* Working with custom fonts
* Comparing an implementation against a provided design

## Features

* Responsive layout
* Centered QR code card
* Mobile and desktop friendly
* Subtle hover animation
* Custom typography using the Outfit font
* Accessible image alternative text

## Getting Started

No build tools or dependencies are required for this project.

### Run Locally

Clone the repository:

```bash
git clone https://github.com/alexandre-delsol/fm-01-qr-code
```

Navigate to the project directory:

```bash
cd fm-01-qr-code
```

Then open `index.html` in your browser.

Alternatively, you can use a local development server such as VS Code Live Server or Python:

```bash
python3 -m http.server 5500
```

Then open:

```text
http://localhost:5500
```
